1. 앱 안에 저장되는 정보
‘반주 위주로 검색’의 마지막 체크 상태와 홈에서 마지막으로 선택한 곡 분류를 기기에 저장합니다.
싱키는 회원가입 없이 사용합니다. 최근 재생한 곡, 플레이리스트 이름, 저장한 곡의 제목·영상 주소·썸네일 주소와 반음 설정은 기기의 앱 전용 공간에 저장됩니다. 운영자의 서버로 전송하지 않으며 앱 자체의 클라우드 동기화는 제공하지 않습니다. iOS 또는 iCloud의 기기 백업에 앱 데이터가 포함될 수 있으며, 사용자의 Apple 백업 설정과 정책이 적용됩니다. 자동완성 제안과 썸네일 캐시는 앱 실행 중 메모리에 임시로 보관합니다. 홈에 표시하는 노래방 순위의 곡명·가수·집계 기간·갱신 시각은 오프라인 표시를 위해 기기에 저장합니다.

앱 언어와 최근 재생 기록 저장 여부도 기기에 저장합니다. 기록 저장을 끄면 이후 재생 기록을 추가하지 않으며, 기존 기록은 설정에서 별도로 삭제할 수 있습니다. 보관함에는 영향을 주지 않습니다.

사용자가 보관함 백업을 선택하면 플레이리스트 이름, 곡명·영상 주소·썸네일 주소·저장 키를 선택한 문서 위치에 파일로 내보냅니다. 음원·영상 파일과 최근 기록은 포함하지 않습니다. 백업은 암호화되지 않으며 선택한 저장소에 접근할 수 있는 사람이 읽을 수 있습니다. 클라우드 문서 제공자를 선택하면 해당 제공자가 파일을 전송·보관할 수 있습니다. 복원은 사용자가 선택한 파일을 읽어 현재 보관함에 목록을 추가합니다. 내보낸 파일은 앱 삭제로 지워지지 않으며 해당 저장소에서 직접 삭제할 수 있습니다.

다른 앱에서 YouTube 링크를 싱키로 공유하면, 앱과 공유 확장만 접근할 수 있는 공간에 영상 식별자와 수신 시각을 임시 저장합니다. 싱키를 열어 읽은 뒤 삭제하며, 24시간이 지난 항목은 검색하지 않고 삭제합니다. 공유 확장은 서버에 전송하지 않습니다.

2. 외부 서비스 연결
검색·자동완성 요청에는 앱 언어에 대응하는 언어·국가 설정이 포함됩니다. 반주 검색을 켠 경우 검색어에 언어별 반주 키워드를 추가할 수 있습니다.
검색·자동완성·영상 재생·썸네일 표시를 위해 Google/YouTube 및 해당 콘텐츠 제공 서버에 직접 연결합니다. 자동완성은 검색 버튼을 누르기 전에도 입력을 잠시 멈추면 입력한 검색어 일부 또는 전체를 전송합니다. 선택한 영상의 식별 정보와 검색어가 요청에 포함될 수 있고, 인터넷 통신 과정에서 접속 IP 주소와 요청 헤더가 서버에 전달됩니다. 외부 서비스의 보관·처리는 해당 서비스의 정책을 따릅니다.
Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko

홈의 한국 곡 차트를 갱신할 때는 TJ미디어, 일본 곡 차트를 갱신할 때는 JOYSOUND(XING)의 공개 차트에 직접 연결합니다. 차트 종류·집계 기간 또는 공개 페이지 주소를 요청하며, 개인 검색어·재생 기록·플레이리스트는 이 서비스에 전송하지 않습니다. 통신 과정에서 접속 IP 주소와 요청 헤더가 각 서버에 전달됩니다. 팝송 추천 목록은 앱에 포함되어 있어 목록 표시를 위한 차트 요청은 없습니다. 출처나 참고 카탈로그 링크를 누르면 외부 브라우저에서 해당 사이트가 열립니다.
TJ미디어 개인정보처리방침: https://www.tjmedia.co.kr/terms?cate_cd=T01
JOYSOUND(XING) 개인정보처리방침: https://xing.co.jp/privacy

3. 선택적 사용 현황 분석과 광고
사용 현황 분석은 기본적으로 꺼져 있으며 처음 안내 또는 설정에서 동의한 경우에만 Google Analytics for Firebase를 사용합니다. 앱 화면, 검색의 성공·실패와 결과 수, 실제 재생 시간, 키 변경, 곡 저장·예약, 저장한 곡의 재사용, 광고 표시·로드 실패를 분석하여 기능과 안정성을 개선합니다. 이벤트에는 앱 언어·버전, 화면 방향, 숫자·분류 값만 직접 추가합니다. 검색어, 곡 제목·영상 주소, 플레이리스트 이름, 이메일, 음성은 분석 이벤트로 전송하지 않습니다.
Firebase는 앱 인스턴스 식별자, IP 주소에서 유추한 대략적인 지역, 앱·운영체제·기기 정보, 세션·이벤트 시간 등의 진단·이용 정보를 처리할 수 있습니다. 광고 식별자 수집과 광고 개인화 목적의 분석 동의는 꺼져 있습니다. 설정에서 분석을 끄면 이후 분석 수집을 중단하고 기기에 저장된 분석 식별자와 미전송 분석 데이터를 초기화합니다. 이미 전송한 서버 기록이 즉시 삭제되는 것은 아닙니다. 분석을 거절해도 앱의 모든 연습 기능을 이용할 수 있습니다.
홈, 세로 플레이어 아래, 가로 플레이어 위에 Google AdMob 배너를 표시할 수 있습니다. 분석에 동의하지 않아도 광고 SDK는 광고 제공·측정·부정 이용 방지를 위해 IP 주소와 그로부터 추정한 대략적인 위치, 앱 상호작용, 진단 정보, 광고·앱·기기 관련 식별자를 처리할 수 있습니다. 광고 데이터 처리는 선택적 사용 현황 분석과 별개입니다. 정확한 위치 권한은 요청하지 않습니다. 필요한 지역에서는 Google 동의 안내를 제공하며 설정의 ‘광고 개인정보 선택’에서 제공되는 옵션을 다시 열 수 있습니다.
Google은 자신의 서비스 제공을 위해 정보를 다른 국가의 서버에서 처리할 수 있습니다. 서비스별 처리·보관에는 Google 정책과 적용된 동의·프로젝트 설정이 적용됩니다. 계정, 결제, 음성 녹음, 연락처·위치·마이크·카메라 권한은 추가하지 않았습니다.

분석 정보 관련 열람·삭제 요청은 getbathtime@gmail.com으로 문의할 수 있습니다. 로그인 계정이 없어 이메일만으로 특정 앱 인스턴스의 분석 기록을 식별하지 못할 수 있으며, 확인 가능한 범위와 처리 방법을 안내합니다.

iOS 분석 서비스가 연결되지 않은 빌드에서는 설정에 수집하지 않는다고 표시하며 이벤트를 보내지 않습니다. 연결되는 운영 Analytics 속성의 이벤트·사용자 데이터 보관 기준은 2개월이며, 새 활동에 따른 기간 연장을 사용하지 않습니다. 이 기준은 대부분의 합산 표준 보고서나 AdMob의 별도 보관 정책에는 적용되지 않습니다.

4. 보관과 삭제
저장한 곡과 최근 기록은 앱에서 해당 항목을 삭제할 수 있습니다. 기기의 설정 > 일반 > iPhone 저장 공간에서 싱키의 ‘앱 삭제’를 선택하면 앱 데이터도 삭제됩니다. ‘앱 정리하기’는 데이터를 남깁니다. iCloud나 컴퓨터에 남은 기기 백업은 해당 백업 설정에서 별도로 관리해야 합니다. 전체 데이터 삭제나 앱 삭제는 저장한 플레이리스트를 잃을 수 있으므로 사용자가 직접 선택해야 합니다. 외부 서비스가 별도로 처리한 정보의 권리는 해당 서비스의 절차를 이용해야 합니다.

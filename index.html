1. 앱 안에 저장되는 정보

싱키는 회원가입 없이 사용합니다. 최근 재생한 곡, 플레이리스트 이름, 저장한 곡의 제목·영상 주소·썸네일 주소와 반음 설정은 기기의 앱 전용 공간에 저장됩니다. 운영자의 서버로 전송하지 않으며 클라우드 동기화와 Android 자동 백업을 사용하지 않습니다. 자동완성 제안과 썸네일 캐시는 앱 실행 중 메모리에 임시로 보관합니다.

2. 외부 서비스 연결

검색·자동완성·영상 재생·썸네일 표시를 위해 Google/YouTube 및 해당 콘텐츠 제공 서버에 직접 연결합니다. 자동완성은 검색 버튼을 누르기 전에도 입력을 잠시 멈추면 입력한 검색어 일부 또는 전체를 전송합니다. 선택한 영상의 식별 정보와 검색어가 요청에 포함될 수 있고, 인터넷 통신 과정에서 접속 IP 주소와 요청 헤더가 서버에 전달됩니다. 외부 서비스의 보관·처리는 해당 서비스의 정책을 따릅니다.

Google 개인정보처리방침: Google 개인정보처리방침

3. 사용하지 않는 기능

현재 버전에는 운영자용 이용 분석 SDK, 광고 SDK, 계정, 결제, 음성 녹음 기능이 없습니다. 연락처·위치·마이크·카메라 권한을 요청하지 않습니다. 향후 처리 항목이나 목적이 달라지면 방침과 앱 안내를 갱신하며 필요한 경우 동의를 받습니다.

4. 보관과 삭제

저장한 곡과 최근 기록은 앱에서 해당 항목을 삭제하거나 Android 설정에서 싱키의 저장공간/데이터를 지우면 삭제할 수 있습니다. 앱 삭제 시 기기의 앱 데이터도 삭제됩니다. 전체 데이터 삭제나 앱 삭제는 저장한 플레이리스트를 잃을 수 있으므로 사용자가 직접 선택해야 합니다. 외부 서비스가 별도로 처리한 정보의 권리는 해당 서비스의 절차를 이용해야 합니다.

5. 문의 처리

지원 이메일로 사용자가 보낸 내용과 이메일 주소는 문의 답변에 사용합니다. 비밀번호, 신분증, 결제정보 등 민감한 정보를 보내지 마세요. 문의 내역의 열람·정정·삭제를 원하시면 같은 이메일로 요청해 주세요. 문의 내용은 답변과 후속 대응이 끝나면 삭제하며, 법령에 보존 의무가 있으면 그 기간을 따릅니다.

6. 보호 조치와 연락처

앱의 외부 요청은 HTTPS 연결을 사용하며 기기 저장 정보는 앱 전용 공간에 보관합니다. 개인정보 관련 문의나 권리 요청은 바스타임스튜디오(getbathtime@gmail.com)로 보내주세요.

1. 앱 안에 저장되는 정보

‘반주 위주로 검색’의 마지막 체크 상태와 홈에서 마지막으로 선택한 곡 분류를 기기에 저장합니다.

싱키는 회원가입 없이 사용합니다. 최근 재생한 곡, 플레이리스트 이름, 저장한 곡의 제목·영상 주소·썸네일 주소와 반음 설정은 기기의 앱 전용 공간에 저장됩니다. 운영자의 서버로 전송하지 않으며 클라우드 동기화와 Android 자동 백업을 사용하지 않습니다. 자동완성 제안과 썸네일 캐시는 앱 실행 중 메모리에 임시로 보관합니다. 홈에 표시하는 노래방 순위의 곡명·가수·집계 기간·갱신 시각은 오프라인 표시를 위해 기기에 저장합니다.

앱 언어와 최근 재생 기록 저장 여부도 기기에 저장합니다. 기록 저장을 끄면 이후 재생 기록을 추가하지 않으며, 기존 기록은 설정에서 별도로 삭제할 수 있습니다. 보관함에는 영향을 주지 않습니다.

사용자가 보관함 백업을 선택하면 플레이리스트 이름, 곡명·영상 주소·썸네일 주소·저장 키를 선택한 문서 위치에 파일로 내보냅니다. 음원·영상 파일과 최근 기록은 포함하지 않습니다. 백업은 암호화되지 않으며 선택한 저장소에 접근할 수 있는 사람이 읽을 수 있습니다. 클라우드 문서 제공자를 선택하면 해당 제공자가 파일을 전송·보관할 수 있습니다. 복원은 사용자가 선택한 파일을 읽어 현재 보관함에 목록을 추가합니다. 내보낸 파일은 앱 삭제로 지워지지 않으며 해당 저장소에서 직접 삭제할 수 있습니다.

2. 외부 서비스 연결

검색·자동완성 요청에는 앱 언어에 대응하는 언어·국가 설정이 포함됩니다. 반주 검색을 켠 경우 검색어에 언어별 반주 키워드를 추가할 수 있습니다.

검색·자동완성·영상 재생·썸네일 표시를 위해 Google/YouTube 및 해당 콘텐츠 제공 서버에 직접 연결합니다. 자동완성은 검색 버튼을 누르기 전에도 입력을 잠시 멈추면 입력한 검색어 일부 또는 전체를 전송합니다. 선택한 영상의 식별 정보와 검색어가 요청에 포함될 수 있고, 인터넷 통신 과정에서 접속 IP 주소와 요청 헤더가 서버에 전달됩니다. 외부 서비스의 보관·처리는 해당 서비스의 정책을 따릅니다.

Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko

홈의 한국 곡 차트를 갱신할 때는 TJ미디어, 일본 곡 차트를 갱신할 때는 JOYSOUND(XING)의 공개 차트에 직접 연결합니다. 차트 종류·집계 기간 또는 공개 페이지 주소를 요청하며, 개인 검색어·재생 기록·플레이리스트는 이 서비스에 전송하지 않습니다. 통신 과정에서 접속 IP 주소와 요청 헤더가 각 서버에 전달됩니다. 팝송 추천 목록은 앱에 포함되어 있어 목록 표시를 위한 차트 요청은 없습니다. 출처나 참고 카탈로그 링크를 누르면 외부 브라우저에서 해당 사이트가 열립니다.

TJ미디어 개인정보처리방침: https://www.tjmedia.co.kr/terms?cate_cd=T01

JOYSOUND(XING) 개인정보처리방침: https://xing.co.jp/privacy

3. 선택적 사용 분석과 광고

사용 분석은 기본적으로 꺼져 있으며, 안내창 또는 설정에서 동의한 경우에만 PostHog, Inc.의 EU 수집 서버(독일 프랑크푸르트)에 HTTPS로 이벤트를 보냅니다. 이전 Firebase 분석 동의를 새 서비스의 동의로 사용하지 않습니다. 처리 목적은 기능 개선과 안정성 확인입니다.

전송 항목은 앱 화면, 검색 성공·실패와 결과 수, 실제 연습 시간, 키 변경·저장·예약과 저장곡 재사용 여부, 앱 버전·언어·화면 방향, 이벤트 시각 및 임의로 만든 설치 식별자입니다. 검색어, 곡명, 영상 URL, 목록 이름, 이메일, 음성은 분석 이벤트에 넣지 않습니다. 로그인 계정과 광고 ID를 사용하지 않으며 화면 녹화·자동 클릭 수집·맞춤 광고를 하지 않습니다.

인터넷 통신에는 IP 주소와 요청 헤더가 전달됩니다. 분석용 IP 위치 변환은 끄며, IP 주소를 이벤트에 보관하지 않도록 프로젝트를 설정합니다. 서비스 운영·보안 처리와 국외 처리는 PostHog의 개인정보처리방침과 하위 처리자 정책을 따릅니다.

동의하지 않아도 모든 연습 기능을 사용할 수 있습니다. 설정에서 분석을 끄면 새 전송을 중지하고 전송 중 요청을 취소하며 기기의 분석 식별자와 미전송 대기열을 지웁니다. 이미 서버에 도착한 기록이 즉시 삭제되는 것은 아닙니다. 미전송 이벤트는 기기 메모리에만 제한된 수로 보관하며 오프라인 또는 앱 종료 시 일부가 유실될 수 있습니다.

무료 플랜은 이벤트 데이터의 1년 보관을 제공하며, 이는 1년 뒤 자동 삭제를 보장하는 기한은 아닙니다. 열람·삭제 요청은 getbathtime@gmail.com으로 연락해 주세요. 로그인 없이 만든 식별자를 사용하므로 이메일만으로 과거 이벤트를 특정하지 못할 수 있으며 확인 가능한 범위와 삭제 절차를 안내합니다. 보관·삭제는 서비스의 실제 정책과 절차를 따릅니다.

PostHog 개인정보처리방침: https://posthog.com/privacy

데이터 보관·삭제 안내: https://posthog.com/docs/privacy/data-storage

이 배포본에는 Google 광고 SDK·UMP·Firebase Analytics SDK가 포함되지 않으며 광고를 표시하거나 요청하지 않습니다. 이후 광고를 도입할 때에는 개인정보 안내와 필요한 동의를 먼저 갱신합니다.

4. 보관과 삭제

저장한 곡과 최근 기록은 앱에서 해당 항목을 삭제하거나 Android 설정에서 싱키의 저장공간/데이터를 지우면 삭제할 수 있습니다. 앱 삭제 시 기기의 앱 데이터도 삭제됩니다. 전체 데이터 삭제나 앱 삭제는 저장한 플레이리스트를 잃을 수 있으므로 사용자가 직접 선택해야 합니다. 외부 서비스가 별도로 처리한 정보의 권리는 해당 서비스의 절차를 이용해야 합니다.

문의 화면에는 지원 메일 주소(getbathtime@gmail.com)만 표시합니다. 앱 내 문의 폼과 자동 전송 기능은 사용하지 않습니다. 주소를 눌러 외부 이메일 앱에서 직접 메일을 작성·전송할 수 있습니다. 이 앱은 앱·Android 버전, 재생 기록, 보관함이나 기기 식별 정보를 문의에 자동 첨부하지 않습니다.

운영자는 사용자가 직접 보낸 이메일 주소와 내용을 문의 처리와 답변에 사용합니다. 이메일의 전송·보관에는 사용자가 선택한 메일 서비스와 운영자의 Gmail 서비스가 관여하며 각 서비스의 개인정보처리방침이 적용됩니다.

비밀번호, 신분증, 결제정보 등 민감한 정보를 보내지 마세요. 문의 내역의 열람·정정·삭제를 원하시면 같은 이메일로 요청해 주세요. 문의 메일은 답변과 후속 대응이 끝나면 운영자가 삭제하며, 법령에 보존 의무가 있으면 그 기간을 따릅니다. 문의를 보내지 않아도 검색·재생·보관함을 사용할 수 있습니다.

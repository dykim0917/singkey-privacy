1. 앱 안에 저장되는 정보

‘반주 위주로 검색’의 마지막 체크 상태와 홈에서 마지막으로 선택한 곡 분류를 기기에 저장합니다.
내키로의 기본 검색·연습 기능은 회원가입 없이 사용합니다. 최근 재생한 곡, 플레이리스트 이름, 저장한 곡의 제목·영상 주소·썸네일 주소와 반음 설정은 기기의 앱 전용 공간에 저장됩니다. 7절에서 설명하는 사용자의 명시적 공개 게시 외에는 운영자의 서버로 전송하지 않으며 개인 보관함의 클라우드 동기화와 Android 자동 백업을 사용하지 않습니다. 자동완성 제안과 썸네일 캐시는 앱 실행 중 메모리에 임시로 보관합니다. 홈에 표시하는 노래방 순위의 곡명·가수·집계 기간·갱신 시각은 오프라인 표시를 위해 기기에 저장합니다.

앱 언어와 최근 재생 기록 저장 여부도 기기에 저장합니다. 기록 저장을 끄면 이후 재생 기록을 추가하지 않으며, 기존 기록은 설정에서 별도로 삭제할 수 있습니다. 보관함에는 영향을 주지 않습니다.

현재 버전에서는 파일 백업·복원을 제공하지 않습니다. 이전 버전에서 내보낸 백업에는 플레이리스트 이름, 곡명·영상 주소·썸네일 주소·저장 키와 곡별 기록이 포함될 수 있습니다. 파일은 암호화되지 않아 저장소에 접근할 수 있는 사람이 읽을 수 있고, 클라우드 저장소의 전송·보관에는 해당 제공자의 정책이 적용됩니다. 기존 파일은 앱 삭제로 지워지지 않으며 해당 저장소에서 직접 삭제할 수 있습니다.

사용자가 직접 남긴 곡별 평가(낮음·편함·높음), 평가 당시 키·날짜, 메모와 연습 상태는 기기 안에 저장하며 운영자의 서버·분석 이벤트로 보내지 않습니다. 최근 재생 기록 설정과 별개로 사용자가 저장한 내용만 보관합니다. 곡별 최신 기록은 최대 500곡이며 설정의 곡별 연습 기록에서 수정·삭제할 수 있습니다. 전체 평가 이력이나 연습 시간 리포트를 수집하는 기능은 아닙니다.

제출한 검색어는 별도 검색 기록 설정에 따라 최대 10개를 기기에 저장합니다. URL과 입력 중 자동완성 문구는 이 기록에 넣지 않습니다. 검색 기록을 끄면 표시와 추가 저장을 중단하고 기존 기록은 유지하며, 개별 또는 전체 삭제할 수 있습니다. 마지막 연습 곡·키·확인된 본편 위치·예약 순서는 기기에 저장하여 사용자가 직접 이어갈 수 있게 합니다. 개인 저장곡 추천은 이 기기의 저장곡·최신 평가·남아 있는 재생 날짜만 사용하고 설정에서 끌 수 있습니다. 검색 기록과 이어가기 상태는 분석 이벤트에 포함하지 않습니다. 이 기능들로 새로운 서버 전송이나 클라우드 백업을 추가하지 않습니다.

2. 외부 서비스 연결

검색·자동완성 요청에는 앱 언어에 대응하는 언어·국가 설정이 포함됩니다. 반주 검색을 켠 경우 검색어에 언어별 반주 키워드를 추가할 수 있습니다.
검색·자동완성·영상 재생·썸네일 표시를 위해 Google/YouTube 및 해당 콘텐츠 제공 서버에 직접 연결합니다. 자동완성은 검색 버튼을 누르기 전에도 입력을 잠시 멈추면 입력한 검색어 일부 또는 전체를 전송합니다. 선택한 영상의 식별 정보와 검색어가 요청에 포함될 수 있고, 인터넷 통신 과정에서 접속 IP 주소와 요청 헤더가 서버에 전달됩니다. 외부 서비스의 보관·처리는 해당 서비스의 정책을 따릅니다.
영상 재생은 앱 내부 WebView의 YouTube 내장 플레이어와 공식 재생 제어 API를 사용합니다. 플레이어의 로그인·광고 등 재생 환경 유지를 위해 YouTube의 서드파티 쿠키를 허용하며, YouTube는 자체 쿠키·웹 저장소를 사용하고 광고를 표시할 수 있습니다. 이 처리는 내키로의 선택적 PostHog 분석과 별개이며 Google의 정책을 따릅니다. WebView의 파일 접근과 마이크·카메라 권한 요청은 허용하지 않습니다.
Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko

3. 선택적 사용 분석과 광고

사용 분석은 기본적으로 꺼져 있으며, 안내창 또는 설정에서 동의한 경우에만 PostHog, Inc.의 EU 수집 서버(독일 프랑크푸르트)에 HTTPS로 이벤트를 보냅니다. 이전 Firebase 분석 동의를 새 서비스의 동의로 사용하지 않습니다. 처리 목적은 기능 개선과 안정성 확인입니다.
전송 항목은 앱 화면, 검색 성공·실패와 결과 수, 실제 연습 시간, 키 변경·저장·예약과 저장곡 재사용 여부, 배너 위치별 노출·로드 실패, 앱 버전·언어·화면 방향, 이벤트 시각 및 임의로 만든 설치 식별자입니다. 검색어, 곡명, 영상 URL, 목록 이름, 이메일, 음성은 분석 이벤트에 넣지 않습니다. PostHog 분석은 로그인 계정과 광고 ID를 사용하지 않으며 화면 녹화·자동 클릭 수집·맞춤 광고를 하지 않습니다.
인터넷 통신에는 IP 주소와 요청 헤더가 전달됩니다. 분석용 IP 위치 변환은 끄며, IP 주소를 이벤트에 보관하지 않도록 프로젝트를 설정합니다. 서비스 운영·보안 처리와 국외 처리는 PostHog의 개인정보처리방침과 하위 처리자 정책을 따릅니다.
동의하지 않아도 모든 연습 기능을 사용할 수 있습니다. 설정에서 분석을 끄면 새 전송을 중지하고 전송 중 요청을 취소하며 기기의 분석 식별자와 미전송 대기열을 지웁니다. 이미 서버에 도착한 기록이 즉시 삭제되는 것은 아닙니다. 미전송 이벤트는 기기 메모리에만 제한된 수로 보관하며 오프라인 또는 앱 종료 시 일부가 유실될 수 있습니다.
무료 플랜은 이벤트 데이터의 1년 보관을 제공하며, 이는 1년 뒤 자동 삭제를 보장하는 기한은 아닙니다. 열람·삭제 요청은 getbathtime@gmail.com으로 연락해 주세요. 로그인 없이 만든 식별자를 사용하므로 이메일만으로 과거 이벤트를 특정하지 못할 수 있으며 확인 가능한 범위와 삭제 절차를 안내합니다. 보관·삭제는 서비스의 실제 정책과 절차를 따릅니다.

광고
홈과 세로 플레이어에 Google AdMob 배너 광고를 표시합니다. 전면 광고나 보상형 광고는 사용하지 않습니다. 광고는 선택적 PostHog 분석과 별개이며, 분석을 꺼도 광고 처리가 중지되는 것은 아닙니다. Firebase Analytics SDK는 포함하지 않습니다.
Google Mobile Ads SDK는 광고 제공·측정·분석·부정 사용 방지를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 앱·광고 상호작용, 진단·성능 정보, Android 광고 ID·앱 세트 ID 등의 기기 식별자를 수집·공유할 수 있습니다. 광고 ID는 Android 설정에서 삭제하거나 재설정할 수 있습니다. 개발자는 검색어·곡명·영상 URL·보관함·음성을 광고 요청에 직접 추가하지 않습니다.
Google UMP를 통해 지역에 따라 필요한 동의·거부 선택을 제공하고, SDK가 광고 요청을 허용한 뒤 초기화합니다. 동의가 필요한 지역에서는 설정의 ‘광고 개인정보 선택’에서 선택을 변경할 수 있습니다. 동의를 거부해도 연습 기능을 이용할 수 있으며, 해당 선택과 지역에 따라 제한된 광고가 표시되거나 광고가 표시되지 않을 수 있습니다.
광고 관련 정보는 전송 중 TLS로 암호화됩니다. Google과 광고 파트너의 처리·국외 전송·보관·삭제는 해당 서비스의 정책을 따릅니다. PostHog 분석 동의 철회가 Google에 이미 전달된 정보를 삭제하지는 않습니다.
Google 광고 개인정보 안내: https://policies.google.com/technologies/ads?hl=ko

4. 보관과 삭제

저장한 곡과 최근 기록은 앱에서 해당 항목을 삭제하거나 Android 설정에서 내키로의 저장공간/데이터를 지우면 삭제할 수 있습니다. 앱 삭제 시 기기의 앱 데이터도 삭제됩니다. 전체 데이터 삭제나 앱 삭제는 저장한 플레이리스트를 잃을 수 있으므로 사용자가 직접 선택해야 합니다. 외부 서비스가 별도로 처리한 정보의 권리는 해당 서비스의 절차를 이용해야 합니다.
